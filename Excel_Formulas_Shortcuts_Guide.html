Useful Excel tips

1. Start formulas with =
Example: =SUM(B2:B20)

2. Use absolute references
$A$1 keeps both row and column fixed when copying a formula. Press F4 while editing a reference to cycle reference types (Windows desktop).

3. Handle errors
=IFERROR(A2/B2,0) returns 0 if the calculation causes an error.

4. Convert data into a Table
Use Ctrl + T (Windows) to make a structured table that expands with your data.

5. Version compatibility
Functions such as XLOOKUP, FILTER, SORT, UNIQUE, LET and LAMBDA are available in newer Microsoft 365 / Excel versions. Older editions may not support them.

6. Locale differences
Some Excel installations use semicolons instead of commas between function arguments, depending on regional settings.

7. Shortcuts can vary
Listed shortcuts primarily target Excel for Windows desktop. Excel for Mac, Excel for the web, and different keyboard layouts may behave differently.
